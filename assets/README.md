# Setlist artwork

Setlist uses a terminal prompt beside three track lines on a coral tile.
The tile is `#ff4f70`, the dark ink is `#18181e`, and the light lettering is
`#f6f3ef`.

| File | Use |
| --- | --- |
| `logo.svg` | Logo on light backgrounds; 256 × 84, scalable |
| `logo-dark.svg` | Logo on dark backgrounds; 256 × 84, scalable |
| `logo.png` | Transparent logo for light backgrounds; 1024 × 336 |
| `favicon.svg` | Scalable icon and source for the favicon exports |
| `favicon.png` | Transparent icon; 512 × 512 |
| `favicon.ico` | Browser favicon; 16, 32 and 48 pixels |

The SVG lettering is outlined and needs no installed font. Keep the SVGs as
the editable originals and regenerate the PNG and ICO files when they change.
